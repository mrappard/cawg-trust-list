The link:https://cawg.io/identity/[CAWG identity assertion] allows a _named actor_ to sign an identity assertion with an X.509 certificate (signature type `cawg.x509.cose`).
Validators decide whether to trust that certificate using the *CAWG trust configuration*: a set of accepted Extended Key Usage (EKU) values, each with accepted certificate policies and trust anchors.

This document proposes the *CAWG Trust List*: the certificate policy, trust anchors, and governance process that populate the CAWG trust configuration so that certificates issued to CAWG members can be recognised as trusted.
It follows the model of the link:++https://spec.c2pa.org/specifications/specifications/2.4/specs/C2PA_Specification.html#_trust_lists++[C2PA Trust List].
